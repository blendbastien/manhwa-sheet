# Manhwa Sheet 1.0

Standalone Foundry VTT v13 system for manhwa-style play (hunters, regressors, murim, system apocalypses).

**v0.1 scope (test build):** configurable stats, currencies, ranks & color behavior, awakening states, origins, lists (rarities, elements, costs, ranges, executions), item category tree with inherited field sets, identity sections, progression (paid stats off by default; cost by tiers / formula / one by one; caps; tiers), themes (GM-imposed world setting), character sheet (header, stats, identity, item tabs built from the tree, optional Equipped tab), item sheet.

Everything lives in **Configure Settings → Manhwa Sheet**: *Sheet configuration*, *Progression & costs*, *Theme*. Export/import the configuration as JSON.

Fonts bundled under OFL (Orbitron, Rajdhani, Share Tech Mono, Cinzel). Icons: Font Awesome Free (shipped with Foundry).

**v0.2** — rich text editors (ProseMirror, toggled) for identity long texts, item descriptions and lore; description column in item tables, folded past N characters with a block tooltip (hover to read, click to pin); search and sort per item table; item sheet fields follow the category.

**v0.3** — level-up and stat-tier notices (chat, plus the Manhwa Notices module when active; texts configurable under Progression → Notices); equipped bag grants extra body slots; paid stats, caps, tiers, seals, equipped title, folded descriptions all configurable.

**1.0** — default item taxonomy aligned with the Catalogue (8 types › families › 187 categories › sub-categories, 1 079 nodes, English, generic), category picker with cascading columns (sheet « New … » button and item sheet « Change »), no more per-item « equippable » flag (equip allowed per top-level category, Equipped tab and bag on by default; bags = categories with a Capacity field), portrait shape setting (rectangle / square), bigger Awakening / Rank / Sponsor controls, refined art direction (brackets, cut corners, finer type), level/tier notices off by default, public API `MANHWA.api` (resources, stats, categories, createItem) and hook `manhwaSheetReady`.

## 1.0 — play modes

* **Narrative RPG** (default): the sheet is a tracker — stats, identity, inventory, equipped gear, no dice.
* **General**: Sheet configuration › Play mode. Gauges (health, mana, stamina… with token bars), experience bar (automatic or manual level-up, customizable look), dice (stat rolls, item formulas), stat bonuses on equipped items, quick access per tab. Each feature can be turned off individually.
* **Permissions**: what players may change on their own sheet (level, rank, currencies…).
* **NPC sheet**: full or compact, with a GM-only notes tab.

## Your data across updates

Characters, NPCs and items live in your world and are never rewritten by an update. The configuration is layered over the defaults: lists you changed are kept as they are, new options only fill gaps. Before any configuration migration a backup is stored (Sheet configuration › Safety, last 8, restorable). Deleting a category never deletes items: they are flagged on their sheet until reassigned.
